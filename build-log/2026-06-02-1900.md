## Phase 1 — Core Infrastructure

**Implemented models, config, database, security, and FastAPI skeleton.**

### Models (`marquee/models/`)

| Model | Table | Key features |
|---|---|---|
| `ArtworkMixin` | (mixin) | `poster_*` columns with `poster_` prefix for future extraction |
| `Movie` | `movies` | tmdb_id UNIQUE, radarr_id UNIQUE, has_hdr/has_dv (Phase N), partial index on `poster_path IS NULL` |
| `Series` | `series` | tvdb_id UNIQUE, sonarr_id UNIQUE, season_count, tmdb_id nullable (Phase N) |
| `Season` | `seasons` | FK→series CASCADE, UNIQUE(series_id, season_number), ArtworkMixin |
| `Episode` | `episodes` | FK→series CASCADE, sonarr_episode_id UNIQUE, has_hdr/has_dv, NO poster columns |

**Design decisions:**
- Separate tables (not single `media` table) — movies and shows have different file structures
- `poster_` prefix on all ArtworkMixin columns — enables clean extraction to `artwork` table later
- HDR/DV as nullable booleans (NULL=unchecked, True=has, False=missing)
- Season posters tracked in dedicated `seasons` table, not columns on Series

### Config (`marquee/config.py`)

Pydantic-settings with 40+ fields covering: app, DB, CORS, shutdown, path mapping (Bazarr-style), TMDB/Fanart/TVDB keys, Radarr/Sonarr URLs, sync intervals, poster cache, AI models, OCR, poster filenames, dedup thresholds, rate limit cooldown.

### Database (`marquee/database.py`)

- Async SQLAlchemy + aiosqlite
- WAL mode enabled (concurrent reads during writes)
- Foreign keys enforced via PRAGMA
- DB URL resolves relative to project root (not CWD)
- `get_db()` FastAPI dependency

### Security (`marquee/core/path_utils.py`)

`safe_translate_and_validate()` — 4-layer path guard:
1. Null byte rejection
2. Path translation (ARR_PATH_PREFIX → LOCAL_PATH_PREFIX)
3. Canonical resolution (collapses `..` and symlinks)
4. Root validation (gated behind MEDIA_ROOTS config)

### App Skeleton (`marquee/main.py`)

- FastAPI with lifespan (startup/shutdown)
- CORS middleware (for Phase 6 web UI)
- Health check probes database (returns 200/503)
- Graceful shutdown with configurable timeout
- Request logging middleware (method, path, status, duration)

### Sync Service (`marquee/core/sync_service.py`)

Full *arr → DB sync for all four entity types:

| Method | API calls | Data |
|---|---|---|
| `sync_all()` | Orchestrator | Returns `SyncReport` |
| `_sync_movies()` | 1 × Radarr | Upserts by radarr_id, checks poster existence |
| `_sync_series()` | 1 × Sonarr | Upserts by sonarr_id, cascades to children |
| `_sync_seasons()` | From series response | Upserts by (series_id, season_number), skips season 0 |
| `_sync_episodes()` | N × Sonarr (per series) | Upserts by sonarr_episode_id, joins file paths |

**Key behaviors:**
- Never overwrites poster columns during sync
- Configurable poster filename formats (`MOVIE_POSTER_FORMAT`, `SERIES_POSTER_FORMAT`, `SEASON_POSTER_FORMAT`)
- `{movie_basename}` and `{season:02d}` template variables
- Paths validated through `safe_translate_and_validate()`
- Per-item error resilience (errors counted, sync continues)

## Key Design Decisions

1. **Separate tables** for Movie, Series, Season, Episode — justified by different file structures
2. **`poster_` column prefix** — enables clean extraction to `artwork` table for backdrops/logos
3. **CLIP over DINOv2** — semantic understanding for taste matching
4. **PaddleOCR over Florence-2** — CPU-only, multiprocessing
5. **TMDB-first** — sole poster source for initial pipeline
6. **tvdb_id primary** for series — TMDB resolution deferred to Phase N
7. **SQLite + WAL mode** — concurrent read/write at personal library scale
8. **MEDIA_ROOTS defaults empty** — security whitelist, not a footgun
9. **Test-first** — 31 tests across models and sync
